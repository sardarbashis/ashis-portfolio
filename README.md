## ⚡ Quick Setup

### 1. Clone Repository

```bash
git clone https://github.com/sardarbashis/ashis-portfolio.git
```

### 2. Navigate into Project

```bash
cd ashis-portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm start
```

Open:

```txt
http://localhost:3000
```
